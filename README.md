# Deck — личный дашборд-агрегатор

Каркас на React + Vite. Открывается одной страницей: горизонт-таймлайн текущего
времени суток сверху, ниже — карточки с погодой, курсами валют, активностью на
GitHub и списком задач на день.

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

## Что внутри

| Виджет | Источник | Ключ API нужен? |
|---|---|---|
| Погода | [Open-Meteo](https://open-meteo.com) | нет |
| Курсы валют | [Frankfurter](https://www.frankfurter.app) | нет |
| GitHub-активность | GitHub REST API | нет (публичные события) |
| Задачи на день | локально, `localStorage` | — |

Погода запрашивает геолокацию браузера; при отказе использует запасные
координаты (задаются в `WeatherWidget.jsx`, переменная `FALLBACK`).

GitHub-виджет просит ник при первом запуске и запоминает его в `localStorage`
(ключ `deck.github`).

## Структура

```
src/
  components/
    Header.jsx          — приветствие, часы
    HorizonStrip.jsx    — сигнатурная полоса-таймлайн дня
    Card.jsx            — обёртка карточки-виджета
    WeatherWidget.jsx
    CurrencyWidget.jsx
    GitHubWidget.jsx
    TodoWidget.jsx
  App.jsx                — сборка сетки
  App.css                — вся вёрстка/дизайн-система
  index.css              — цветовые токены и базовые стили
```

## Куда развивать

- Добавить новый виджет: скопировать `Card`-обёртку из любого существующего
  файла в `components/`, подключить в `App.jsx`, добавить класс `card--*` в
  `App.css` для позиции в сетке.
- Вынести обновление данных на интервал (`setInterval` + `useEffect`) — сейчас
  виджеты грузятся один раз при монтировании.
- Спрятать OAuth-сервисы (Spotify, Google Calendar) за отдельный бэкенд —
  фронт с ними напрямую работать не может из-за приватных токенов.
